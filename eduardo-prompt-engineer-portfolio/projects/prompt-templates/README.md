# Biblioteca de Prompt Templates

Coleção de templates prontos e comentados por domínio.

- `engineering.yaml` — checklists, memoriais, diagramas (texto)
- `marketing.yaml` — funis, copys, calendários editoriais
- `cybersec.yaml` — triagem de alertas, hunting e SOAR (texto)
- `printing3d.yaml` — descrições de produto, especificações e cálculos simples
